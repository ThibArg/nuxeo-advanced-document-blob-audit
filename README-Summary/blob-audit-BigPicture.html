nuxeo-advanced-document-blob-audit

The big picture — in one page. For details, see blob-audit-summry-final.html.

When a document gets a new version and its file has really changed, the plugin records that it changed (an audit entry, right away) and what changed inside it (a content diff, computed in the background and kept in a folder only auditors can read).

Four things to remember

Versions, not savesOnly a check-in that replaces a file with different bytes counts.
Never silent"No entry" always means "no change", never "could not tell".
ConfidentialDiffs hold business content; only the auditors group can read them.
